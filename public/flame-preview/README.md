# Flame preview reference asset

`bonfire-reference.jpg` is a local visual reference copied from the user's
`黑魂篝火素材` folder. It is used only on the un-deployed `/flame-preview/`
concept page and should be replaced with an owned or licensed asset before
public deployment.

Original source listed by the user:
https://wallpapercave.com/wp/wp9000049.jpg

`bonfire-embers.webp` is a local derivative of that reference. Neutral stone
and ground highlights are reduced and warmed, while saturated flame colors
are retained. The same preview-only usage applies.
